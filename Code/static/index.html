Betriebssystem

macOS mit Apple Silicon (M1–M4): CPU und GPU teilen sich den Arbeitsspeicher. Es gibt keine separate Grafikkarte.

Windows und Linux: Mit separater Grafikkarte rechnet die GPU im eigenen Grafikspeicher. Ohne Grafikkarte rechnet der Prozessor im Arbeitsspeicher – das ist deutlich langsamer.

GB

Der Arbeitsspeicher ist der schnelle Speicher, in dem ein Modell liegt, während es rechnet. Er ist nicht dasselbe wie die Festplatte, auf der die Modelldatei dauerhaft gespeichert ist.

Wo du den Wert findest: Mac → Apple-Menü → «Über diesen Mac» → Arbeitsspeicher. Windows → Einstellungen → System → Info → Installierter RAM.

Grafikkarte

Bei macOS nicht nötig: Apple Silicon hat keine separate Grafikkarte – die GPU nutzt den Arbeitsspeicher aus Schritt 2.

GB

Eine separate Grafikkarte (z. B. NVIDIA GeForce RTX, AMD Radeon) hat eigenen Grafikspeicher (VRAM) und rechnet KI-Modelle am schnellsten. Der Wert steht auf der Verpackung oder in den Systeminformationen (Windows: Task-Manager → Leistung → GPU).

Apple Silicon hat keine separate Grafikkarte – Schalter aus lassen.

GB

Auf der Festplatte (SSD) wird die Modelldatei dauerhaft gespeichert – je nach Modell 1 bis 40 GB. Wir prüfen, ob der freie Platz für die gewünschte Anzahl Modelle reicht.

Wo du den Wert findest: Mac → «Über diesen Mac» → Speicher. Windows → Explorer → «Dieser PC».

Dein Ergebnis

So wird gerechnet

Arbeitsspeicher, Grafikspeicher, Festplatte – was ist was?

Arbeitsspeicher (RAM) und Grafikspeicher (VRAM) sind schnelle Speicher, in denen ein Modell liegt, während es rechnet. Das Modell muss dort ganz hineinpassen. Die Festplatte (SSD) speichert die Modelldatei dauerhaft – sie bestimmt nur, wie viele Modelle du aufbewahren kannst.

Wie viel Arbeitsspeicher ist für ein Modell nutzbar?

Mit separater Grafikkarte zählt der Grafikspeicher (minus 0.5 GB für den Treiber). Auf Apple Silicon gibt macOS der GPU rund zwei Drittel bis drei Viertel des Arbeitsspeichers frei. Ohne Grafikkarte rechnet der Prozessor – davon sind etwa 75 % des Arbeitsspeichers nutzbar.

Wie viel Arbeitsspeicher braucht ein Modell?

Modellgewichte = Parameter × Bits pro Gewicht ÷ 8 – das ist zugleich die Dateigrösse auf der Festplatte. Dazu kommt der KV-Cache für das Kontextfenster (abhängig von der Modellarchitektur) und rund 0.75 GB Reserve für Rechenpuffer.

Was bedeuten «optimal», «passt» und «knapp»?

Belegt ein Modell höchstens 70 % des nutzbaren Arbeitsspeichers, ist es optimal – es bleibt Reserve für längere Texte und andere Programme. Bis 90 % passt es, bis 100 % ist es knapp, darüber zu gross. Die beste Wahl ist das grösste Modell, das optimal oder passend ist und auf die Festplatte passt.
